# Handoff

**Session journals live in `job_hunt_ai_vault/raw/handoffs/`**, one per session, written from
`TEMPLATE.md` in that directory by the `/handoff` skill. The brief a session starts from is
generated by the librarian at the end of the previous one and printed by a `SessionStart` hook,
so it arrives without anyone asking for it.

To ask what this project knows: **`/vault-ask <question>`**. Ask in Russian if that is the
question you have — the tag dictionary carries the aliases.

If no brief appeared at the top of this session, the hook did not fire. Read
`job_hunt_ai_vault/brief.md` yourself, then say so in section 7 of this session's handoff.

## What used to be here

1289 lines of compiled knowledge — invariants, decisions, lessons, limitations — accumulated
across five slices. It was a knowledge base wearing a handoff's name: every agent paid ~120 KB
at the start of every session whatever the task, and by 2026-08-12 it had begun to contradict
itself, carrying two versions of the same mechanism with nothing in the file to say which was
current — the newest text had been prepended while the per-slice records below it stayed frozen,
so position was no guide at all.

All of it is now in the vault, as pages you can reach by asking. Nothing was deleted:

- the file itself, verbatim, is `job_hunt_ai_vault/raw/handoffs/2026-08-12-handoff-before-the-vault.md`;
- every one of its 332 claims carries a verdict in the sidecar beside it, saying which page it
  became or why it did not become one — `bash scripts/vault-coverage.sh` over that file is what
  says the migration is finished, and it is the gate this retirement had to pass;
- the pre-migration text is also in git history, at `e872992`.
