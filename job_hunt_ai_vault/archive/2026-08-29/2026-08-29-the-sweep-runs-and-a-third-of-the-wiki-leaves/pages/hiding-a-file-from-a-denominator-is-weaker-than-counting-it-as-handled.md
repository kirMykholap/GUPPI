# The choice, and the owner took the wider half

**A criterion had acquired a member it could not describe.** The advisory counts governed files
carrying a marked region, and a fully generated file can never carry one — so it would have been
named as unsatisfied on every run for good
([[the-criterion-on-governed-files-is-reworded-to-admit-full-generation]]).

| the fix offered | what it does |
|---|---|
| **the session's**: drop marker-carrying files from the denominator | the file disappears from the reading |
| **the owner's**: reword the criterion so the file counts as satisfied | the file stays in the reading and is described correctly |

**The owner's is better and the difference is worth keeping: dropping a file from a denominator
hides it; counting it as satisfied says what is true.**

# Why the weaker fix is attractive

**It makes the number look right with a smaller change to the words.** The advisory would have read
the same, the criterion's text would have been untouched, and nothing would have needed the owner.
That is precisely its defect — it repairs the instrument's output rather than the instrument's
question ([[a-denominator-is-walked-off-the-input-list]]).

**And a shrinking denominator is unreadable.** A fraction whose bottom moves cannot be compared with
last week's, and the store has already had to rule on how such a figure is reported
([[the-governed-denominator-may-grow-and-the-criterion-stays-a-file-count]],
[[the-region-coverage-figure-is-dated-where-it-stands]]).

# The general form

**When a measure meets a case it cannot describe, change what the measure asks — do not change what
it looks at.** The first is visible in the criterion's text and has to be agreed; the second is
invisible in the output and needs nobody's agreement, which is how it wins by default.

**This is the third instance in this store of a session proposing the narrower repair and the owner
taking the wider one** ([[a-drifting-list-is-repaired-by-deleting-it-not-extending-it]],
[[the-quantity-field-is-rejected-and-the-rule-stays-unconditional]]).
