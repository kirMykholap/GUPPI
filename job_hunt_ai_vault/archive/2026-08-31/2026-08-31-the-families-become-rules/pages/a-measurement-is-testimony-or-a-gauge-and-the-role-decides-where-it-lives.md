# The ruling, 2026-08-24, and the split is by role rather than by folder

**Testimony is evidence for a claim.** It lives with that claim, **in any folder**, and it **never
mutates**: the claim was made against that number, so changing the number falsifies the record of
why the claim was believed.

**A gauge answers *how much now*.** It has one true value at a time, it **mutates**, and it lands on
an entity page — **as a consequence of what it is, not as a restriction on where measures may go**.

**Rejected: a rule about folders.** The vault's own `CLAUDE.md` had said a measurement is not a page
and the number lives on the `lessons/` page it justifies. That is right about testimony and has
nothing to say about a gauge, which has no claim to sit beside.

# The consequence that bites immediately

**A gauge that can be printed is never written by hand.** If a command answers *how much now*, the
page names the command; writing the reading down creates a second answer that goes false in silence
([[a-printed-register-cannot-drift-and-a-maintained-one-always-has]],
[[a-drifting-list-is-repaired-by-deleting-it-not-extending-it]]).

**That is the principle `--rules` and `--list` were built on, the same day this was ruled** — a rule
register swept from the gate's own headings, and a case list swept from the suite's own file.

# What it changes about a page already retired for this

**The instruction to report a fixed count of unmarked files was a gauge inside a rule.** It is the
block the owner rejected in the ratification sweep, and its successor names no number
([[the-region-coverage-instruction-carries-no-count-and-reports-the-unmarked-files-as-unchanged]]).

# What it does not settle

**How a gauge is written and where the marked section for it goes** is designed and not built
([[the-measure-section-is-a-marked-region-legal-in-any-folder-and-required-nowhere]]).

# Amendment, 2026-08-25 — the prohibition stands, and here is the mechanism that keeps it intact

**A gauge that can be printed is still never written by hand, and this page stays `current`.**

**The mechanism decided on 2026-08-25 does not touch it.** The owner ruled that a script takes the
page and the subject, runs the command the measure region names, and writes the number beside it —
**so no hand writes it** ([[a-gauge-is-written-by-a-script-that-runs-the-command]]).

**The collision was reported before it was read.** A plan gave the writer both a value and a command,
and a value passed in by hand is exactly what this page forbids; what the owner then ruled was the
sweep, where the command is the only input. **The two rulings agree once the writer is a script.**

**Nothing is built**, so the prohibition is doing all the work it was doing yesterday.
