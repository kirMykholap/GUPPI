# The ruling, 2026-08-25

> **owner:** «1) потверждаю 2) потверждаю 3) потверждаю»

**`CLAUDE.md` joins the `governs:` list of
[[a-block-attributed-to-the-owner-is-written-in-his-own-russian]]**, so the instruction reaches a
session in the file it reads at the start rather than only the closing skills.

**It is the replacement for an item `/pre-task` killed.** The plan had proposed giving the feedback
rule a destination that the ritual empties every session, which the vault forbids by name
([[the-feedback-rules-extra-destination-is-withdrawn]]). The obligation those two items share is the
same one: what a session must know before it writes an attributed line has to reach the session.

# What it reverses, and the page it reverses is already retired

**A ruling of 2026-08-21 kept this rule out of the repository's `CLAUDE.md`** as too specific for a
file whose admission test is *what bootstraps the asking, and what is irreversible if missed*
([[core-is-what-bootstraps-the-asking-and-what-is-irreversible-if-missed]]). That page was retired
the same day this was decided, for a different clause
([[the-alphabet-test-behind-the-owner-block-advisory-is-overturned]]).

**The tension is named rather than argued away.** Signing a sentence he did not say is irreversible
in the sense the admission test means — the corpus then reasons from it as his word — and that is
the ground on which the older ruling is not being followed. **Whether it survives contact with the
file is the owner's**, and it is raised in the brief rather than settled here.

# Not done

**Nothing was rendered.** No rule page was edited and `scripts/vault-inject.sh` wrote nothing on the
day this was decided. Until the `governs:` line is changed and the injector run, `CLAUDE.md` carries
no region for this rule.
