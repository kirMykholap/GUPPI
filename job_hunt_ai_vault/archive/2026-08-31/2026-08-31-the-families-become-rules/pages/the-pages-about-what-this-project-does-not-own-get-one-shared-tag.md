# The ruling, 2026-08-23

> **owner: все внешние описать одним тегом "external".**

**About twenty-six pages describe something this project does not own** — PowerShell, Docker
Desktop, work.ua, dou.ua, htmx, Claude Code's configuration loading, Playwright — and they are
split across `entities/` and `concepts/` by the ordinary rule, which asks whether the page is a
noun with properties or a mechanism with consequences. **A reader who wants to know what this
project knows about PowerShell therefore looks in two folders and has no way to know he has looked
in both.**

# Neither option the session put to him

**It offered *leave them split by the same line* against *give them one home*.** He supplied a
third: keep every page exactly where it is and make the set findable by a tag. **The folder answers
*what kind of knowledge is this* and the tag answers *what is it about*, which is what the two
axes were built for** — so a set that cuts across the folders is a tag by construction, and moving
a page would have broken the category rule to fix a retrieval problem.

**Recorded because it is the only ruling of that day where he refused the frame.** Twenty rulings
were ratified and sixteen arrived as options this session composed; on this one he did not choose
from what he was shown ([[a-list-the-owner-must-confirm-is-prose-in-chat-and-not-a-rendered-menu]]).

# The collision with `basis: external`, named rather than resolved

**`external` already exists in this vault as a value of `basis:`**, where it means *an article,
vendor documentation, upstream behaviour* — what the page rests on. As a tag it would mean *the
subject is something we do not own*. **The two overlap and are not the same set**: a page about
Docker Desktop measured on this machine is `basis: measurement` and external in subject, and a page
about our own injector argued from an upstream changelog is `basis: external` and internal in
subject.

**Nothing here decides whether that is tolerable.** It is named so the session that mints the tag
does not discover it, and so the tag's definition in `tags.md` can say which of the two it means.

# It is not built, and the tag is deliberately not minted yet

**No page carries the tag and `tags.md` does not define it.** Minting a tag that selects nothing
would print a dead-tag advisory at once, and applying it needs a judgement about which pages are in
the set — a judgement the ruling does not make and a sweep cannot
([[dynamic-tag-classification-by-a-skill]]).

**What it obliges when it lands:** the definition names which sense of *external* it carries; the
Russian words a question would use become aliases, because that is what the register is for
([[aliases-carry-the-question-across-languages]]); and the density advisory is read afterwards,
since twenty-six pages across two folders may already sit over the per-folder ceiling of ten
([[the-folder-is-the-first-narrowing]]).

# He ordered the minting at the retro of the second session of 2026-08-23

> **owner: отчекань**

**The tag is minted in `tags.md` at the ingest that compiled this section**, with a definition that
names which sense of *external* it carries — the subject is something this project does not own, not
what the page rests on. The collision with `basis: external` is stated in the definition rather than
left for the next reader to rediscover.

**It is applied to one page rather than to the set.** The proposal about the Obsidian CLI is
squarely in the set and was written the same day
([[the-obsidian-cli-as-a-reading-surface-for-this-store]]), so the tag is not dead on arrival.
**Applying it to the other pages this ruling is about is not done**: which of them are in the set is
a judgement about the corpus, and this store sends those to `/vault-lint` rather than to an ingest
([[dynamic-tag-classification-by-a-skill]]).

**Two things this section does not do.** It does not read the density advisory, which cannot say
anything until the set is applied; and it does not decide whether the collision with `basis:
external` is tolerable, which the section above named and left open.
