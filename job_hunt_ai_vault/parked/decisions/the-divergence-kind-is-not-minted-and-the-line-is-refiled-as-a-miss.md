# The ruling, 2026-08-26

*(the owner selected it, against minting a fifth kind.)*

**A session filed a `divergence:` line into `.superpowers/sdd/vault-feedback.md`.** The file accepted
it with a note — it does not refuse an unknown kind — and the owner ruled the line **rewritten as
`miss:`** and the kind not minted.

**The four kinds were chosen on one axis: what cannot be recovered afterwards.** A measurement, a
ruling, a harness item and a miss all disappear if nobody writes them down in the turn.
**A divergence is recoverable** — it is a rule and an action, both of which are in the tree — so it
fails the axis the set was built on.

**And `miss:` already reaches it.** The kind was widened on 2026-08-24 to *anything that burned us*,
which is what a divergence is ([[lint-and-process-stop-being-session-kinds-and-decision-joins]]).

# Rejected

**Rejected: a fifth kind.** Every kind costs a branch in `/ingest`'s filing step and a line in the
template, and a vocabulary that grows by one whenever a session wants a label stops being a
vocabulary ([[harness-is-a-feedback-kind-of-its-own]] is the counter-case: it was minted because
nothing else carried a decided change to an instruction file).

**Rejected: leaving the line filed under a kind that does not exist.** It would be filed by `/ingest`
under nothing, which is the one outcome the four-kind list exists to prevent.
