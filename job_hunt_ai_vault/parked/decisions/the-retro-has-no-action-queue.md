# Decided 2026-08-17: no action queue, for now

**Every action item the retro finds routes into an address that already exists** — a deferral in
`decisions/`, a line in the journal's `Harness` section, or nothing, in which case it was never a
real item. The test is deliberately harsh: an item with nowhere to go is an item nobody was going
to do.

**Rejected for now: a queue of its own.** A queue with no owner becomes a backlog nobody reads, and
a `tasks/` folder has been refused twice in this project on the same ground
([[the-wiki-has-five-folders-and-tasks-is-not-one]], [[proposals-are-a-folder-not-a-status]]).

**Revisited when the project takes on tasks and Beads.** The owner stated on 2026-08-17 that the
project intends to adopt **Beads** for task tracking later; nothing is designed and nothing depends
on it yet. It is named here because **a deferral that names no destination is a deferral nobody can
pick up** — this decision is explicitly deferred *to* that adoption.

## What it obliges

- The `Harness` section of the journal stays the only work queue the ritual has
  ([[a-harness-change-is-recorded-when-it-is-decided]]), and it is drained by an ingest rather than
  by anyone working through it.
- **An item routed to "nothing" is a claim, not a shrug**, and the retro is the step that has to
  make it out loud.
