# The ruling, 2026-08-26, in his own words

> **owner:** «вопрос про каталог снимаем»

**The recommendation to add a `binding:` column to `scripts/vault-catalogue.sh` is withdrawn**, and
the question comes off the list.

# It was withdrawn because it was never checked

**The recommendation was given without checking who runs the script.** His one-line question
prompted the check, and the check was decisive: **measured 2026-08-26, the word `vault-catalogue`
appears nowhere in the repository outside the scripts themselves and their selftest — zero mentions
in `.claude/`.** No skill and no agent calls it.

**So a column would have been built into an instrument with no reader**, which is the exact failure
this store already names ([[an-admission-test-for-mechanisms]],
[[a-recommendation-given-without-checking-its-subject-is-delivered-like-one-that-was-checked]]).

**Corrected: that measurement was false the day it was taken, and it went false on 2026-08-21.**
The date is the day the text stopped being true, not the day this note was written
([[the-date-of-a-correction-note-is-the-date-the-text-became-false]]). `.claude/` has named the
script continuously since commit `fd812e8` of 2026-08-21, which put `bash scripts/vault-catalogue.sh`
into `.claude/skills/pre-task/SKILL.md:21`; commit `35163c9` of 2026-08-22 moved that line into
`.claude/agents/pre-task.md`, where it stands today at line 108. **`/pre-task` calls the script**, so
the clause *zero mentions in `.claude/`* was already five days false when it was measured. The
sentence above is left standing rather than edited.

**The ruling survives the correction and its ground does not.** The owner withdrew the question, and
a withdrawal is his to make against whatever he likes — it is not a reading of the tree. What is
false is the reason recorded under it: a column here would not have been built into an instrument
with no reader, because the instrument had one. `.claude/settings.local.json` names the script too
and is untracked, so it is evidence of nothing either way.

# Where the real question went

**Whether the catalogue reaches anyone at all is the reading-funnel question**, and the item is bound
into its order rather than standing alone
([[the-reading-funnel-is-delivered-as-a-procedure]]). Building a column first would settle the
narrow question in the wrong direction: an instrument gains a feature and still has no caller.

# Rejected

**Rejected: building the column.** **Rejected: deferring it**, which would leave it on the list to be
re-proposed by a session that does not know it was checked.
