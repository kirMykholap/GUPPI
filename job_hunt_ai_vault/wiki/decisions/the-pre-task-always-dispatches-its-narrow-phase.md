# The ruling, 2026-08-22

**Owner selected: the ritual dispatches phase 2 every time.** The standing instruction against
spawning agents unasked is about work a session chooses to hand off; **it does not reach a ritual
whose second phase is the dispatch**.

**Rejected: obeying the instruction and putting the phase-2 question to oneself in writing.** That is
not a review — the shortlist is built by the party that wrote the plan, so asking it to find its own
holes leaves the fork resolved by whoever created it
([[a-gap-named-by-a-reviewer-is-closed-by-a-mechanism-rather-than-by-care]]).

# Why it had to become a ruling rather than a reminder

**Phase 2 has failed to run on both days the corpus records for it** — 2026-08-21, when the plan was
approved on phase 1 alone, and 2026-08-22, when it was read by hand. **The clause it exists for —
say what is MISSING from this list — was therefore put to nobody, twice**
([[the-pre-task-splits-into-a-cheap-enumeration-and-a-narrow-dispatch]],
[[the-pre-task-ran-at-half-strength-and-the-permission-to-dispatch-arrived-after-the-plan-was-approved]]).

**Skipping the dispatch does not degrade phase 2 to a cheaper phase 2. It removes the only review
phase 1 has.**

# The measured cost, on the run rather than argued

**The shortlist named four pages taking a disposition from the rule the owner struck, and there were
five.** The fifth, [[the-pre-task-becomes-an-agent-and-the-ritual-is-enforced]], cites the struck
page for *"the gate that watches for it stops advising and starts refusing"* — a disposition, not
context — and its title says nothing about hooks, so a list built from `title:` and `authority:`
could not see it. **It surfaced in the librarian's execution, not in the check.**

**And a dispatch that is only asked to execute still reviews its brief, which is the argument
itself.** The same librarian was told that a correction was owed on [[session-hooks]], found it had
been made a day earlier, said so and wrote nothing. **Both findings are what phase 2 buys, and this
session did not spend it** ([[a-pre-task-paid-for-itself-in-findings-nobody-would-have-made]],
[[one-librarian-behind-every-caller]]).

# What it does not settle

**The price of phase 2's read is still unmeasured**, because it has still never been run. The figure
standing beside it in the corpus is the price of a narrow *write*
([[a-cost-figure-attached-to-the-wrong-unit-discourages-the-thing-it-prices]]).

**And the ritual is not thereby enforced.** Enforcement is the blocking write gate, which is gated on
a different chain ([[the-pre-task-becomes-an-agent-and-the-ritual-is-enforced]],
[[a-pre-task-agent-and-a-post-tool-use-hook-that-writes-its-row]]).

# The citation is repointed, and the mechanism honouring this ruling is not the one it names — 2026-08-22

**`sources:` cited `.claude/skills/pre-task/SKILL.md` and now cites `.claude/agents/pre-task.md`.**
The skill was deleted later on the same day this ruling was taken
([[the-pre-task-becomes-an-agent-and-the-ritual-is-enforced]]), and rule 5 of the gate requires every
repository path in `sources:` to resolve — a citation to a file that is not there reads as provenance
and is not ([[vault-scripts]]). **The address moves and the history stays readable**: the ruling was
taken against the skill, in the morning, and is recorded as it was taken.

**The ruling holds and the shape it names is gone.** *The ritual dispatches phase 2 every time* was
an instruction to the **caller**, who could run phase 1 and stop. In the agent both phases happen in
one body, and the agent is told it dispatches nobody — with this page's own argument given as the
ground: when the enumeration lived in the caller and only the reading was dispatched, the empty case
left no dispatch at all, so nothing could tell **checked and found nothing** from **did not check**.
**So the outcome is structural rather than obeyed**, and this page's title names a dispatch that no
longer happens inside the ritual: the dispatch is now of the pre-task agent itself, by the caller.

**What the ruling still forbids is unchanged**: performing phase 1 and calling the ritual done. The
failure it was written against is now reachable only by not dispatching the agent at all.
