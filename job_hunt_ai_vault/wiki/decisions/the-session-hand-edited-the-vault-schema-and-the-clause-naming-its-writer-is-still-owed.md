# The divergence, recorded 2026-08-19

**What the rule says:** the librarian is the only writer of `wiki/`, and the clause added on
2026-08-17 extends that to the registers — `index.md`, `tags.md`, `sprint.md`, `log.md`
([[the-librarian-writes-unattended]], [[the-one-writer-rule-covers-the-registers-too]]).

**What was done:** the main session edited `job_hunt_ai_vault/CLAUDE.md` by hand, twice. First it
removed the `quantity:` example from the frontmatter block and rewrote the `### quantity` section as
*Titles and filenames*, because the field was gone and its **absence** is what has to be documented.
Later it added both boundaries closed that night — that the rule reads the title and the filename and
never the body, and that a title's length is unmeasured
([[the-no-quantity-rule-reads-the-title-and-the-filename-and-never-the-body]],
[[the-length-of-a-title-is-unbounded-and-no-check-measures-it]]).

**Rejected: obeying the rule and routing both edits through the librarian.**

> **owner: the schema file is the session's to hand-edit, with the divergence recorded.**

Authorised in the retro rather than assumed, which is the only thing that distinguishes this from
the class it belongs to ([[ask-before-weakening-or-working-around-a-rule]]).

# Why it looked unnecessary, and this is the part worth keeping

**No decision names who may write `job_hunt_ai_vault/CLAUDE.md`.** The one-writer rule closed `wiki/`
and then the registers; the schema file is neither. It is the store's constitution, it is what the
librarian's own instructions tell it to read first, and **nothing says whose it is to change.**

**This is the second hand-edit of this same file on the record as a divergence for the same reason.**
The first is [[hand-edits-of-the-wiki-are-a-recorded-divergence]], where the owner's permission
covered "the clauses added to the vault's own `CLAUDE.md`" as a rider to a permission about `wiki/`.
Twice is the signal: **the clause is owed**, and until it exists every edit of this file is either an
unrecorded gap or a divergence recorded for a rule that does not quite reach it.

**What the clause has to say, when someone writes it:** whether the schema file is the librarian's
like the registers, the owner's alone, or a session's with a recorded divergence — and if the last,
whether the recording is the whole of the obligation. Any of the three closes it. None of them is the
librarian's to choose ([[the-librarian-writes-unattended]]).

# What made these two edits safe, and neither property is written into any rule

The same pair that made the 2026-08-17 hand-edits safe: **no concurrency** — the librarian had
returned before each edit — and **the change was reviewable**, being a `git diff` against a file the
next session reads at start. Neither is guaranteed by anything, which is the standing weakness of an
enforcement model that is git plus the log rather than a gate.

# The state it leaves

The vault's `CLAUDE.md` now carries *Titles and filenames* with both boundaries in it. A `- lint:`
line filed earlier the same day — *"the vault's `CLAUDE.md` still describes the rule without its
boundaries, and that is reported rather than fixed"* — was **discharged by the second of these two
hand-edits**, which is precisely the ambiguity this page is about: the librarian reported it as not
its to fix, and the session fixed it.

# The clause exists — 2026-08-19, later the same day

**The gap this page names is closed**, and it is closed wider than this page asked:
[[what-the-gate-reads-as-its-own-input-is-the-sessions-to-write]] covers **both**
`job_hunt_ai_vault/CLAUDE.md` **and** every `wiki/*/_schema.yaml`.

> **owner: what the gate reads as its own input is the session's to write.** The owner reads the diff
> before the commit, the librarian writes neither, and **no divergence is recorded for either.**

**Of the three exits this page listed, none was taken as written.** It offered *the librarian's, like the
registers*; *the owner's alone*; and *a session's with a recorded divergence*. The answer is the third
without the recording — and the reason is exactly the two properties the section below this one names as
written into no rule: **the clause states them instead of the paperwork.** No concurrency, and a diff the
owner reads.

**This divergence stands as history and is not retracted.** What happened here happened before the clause
existed, and the record of it is what produced the clause. A future edit of either file is not a
divergence and nothing is filed against it.

*Written in place rather than by rewriting this page, and the `authority: vault-schema-write-permission`
slug above now sits on the page that records the gap rather than on the one that closes it. Whether the
slug should move is raised in the brief; moving it is a judgement about which page owns the question, and
that is not the librarian's to take alone.*

**Why that is the right way round.** An `authority:` slug names the page a reader is sent to for a
question ([[an-authority-register-on-the-model-of-the-tag-dictionary]] is the design that would make
that navigable). A page whose answer is *this is not decided yet* is the wrong destination the
moment it is decided — it is a true record of a day, and it stops being the answer.

**Nothing here is withdrawn.** The divergence stands as recorded, and so does the reasoning that led
to the clause. What moved is one line of frontmatter, and this section is the record that it moved
