# Measured 2026-08-17 at `814472a`, rather than assumed

**The file exists, it is 29 lines, and it is a pointer.** `wc -l docs/HANDOFF.md` → 29. It names
where journals live, how the brief arrives, how to ask the vault a question, and what the 1289-line
knowledge base that used to be here became.

**Nothing in this session touched it, and that is the interesting part.** The whole of the session's
work was about where a rule lives and how it reaches a reader, and this file — the one the repository
`CLAUDE.md` used to name as *"a pointer to the above, and nothing else"* — was never consulted, never
edited and never in the way. Its status is therefore **measured rather than assumed**: it is not
stale, it is not wrong, and the project simply no longer routes through it
([[the-handoff-splits-into-a-handoff-and-a-knowledge-base]]).

## It carries a copy of the mapping that was supposed to have been swept

Line 13 reads *"then say so in **section 7** of this session's handoff"*. The handoff's sections lost
their numbers on 2026-08-17 and the cut is now by heading text
([[the-handoff-template-moves-out-of-raw-and-drops-its-numbers]]). The sweep that found six copies of
that string found them in both `CLAUDE.md`s, three skills, an agent and the template — **and not
here, because `docs/` is outside the governed set**, which is both `CLAUDE.md` files and every
markdown under `.claude/` ([[the-governed-set-is-swept-and-markdown-by-property]]).

**So this is a seventh copy, found by a librarian reading the file rather than by any sweep**, and it
is the cleanest available demonstration of what a swept set does and does not cover
([[a-copied-list-drifts-and-a-sweep-cannot]], [[the-mapping-is-documented-at-each-hop-and-copied-nowhere]]).
Whether `docs/` joins the governed set is an open question with nobody's decision behind it.

## Why it is not simply deleted

Nothing is deleted here ([[raw-holds-testimony-and-artefacts-are-frozen]]), and the file answers one
question no page answers as directly: *what happened to the 1289 lines*. It names the frozen journal,
the sidecar that proves the migration complete, and the commit before it — which is the retirement
gate this project now applies to every source ([[handoff-retires-only-when-every-unit-has-a-verdict]]).
