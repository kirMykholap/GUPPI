# The ruling, 2026-08-23

**owner selected: вычеркнуть пункт совсем.** The line in the vault's own `CLAUDE.md` that reads
*"`concepts` describes the **product**; `lessons` describes **us, working on the product**"* leaves
that file.

**A selection and not an utterance** — he chose it from options this session composed, so the label
stands verbatim and unquoted and none of it is signed as his words
([[the-retro-records-a-ruling-chosen-from-a-menu-and-ratifies-decisions-not-utterances]]).

# The measurement it was decided on

**Of 103 pages in `wiki/concepts/`, about 19 are about the product.** The clause was written when
the store was three days old and the product was what it was about; the corpus has since become
overwhelmingly about the harness that maintains it, and the clause describes about one page in
five.

**Chosen against keeping the clause and splitting product mechanisms from harness mechanisms.** A
split is a seventh category or a mandatory tag, and it would have to be applied to 103 pages by a
judgement no sweep can make — which is the reason the harness-versus-product finding was recorded
and not acted on the day before ([[the-harness-versus-product-split-is-recorded-and-not-acted-on]],
[[an-admission-test-for-mechanisms]]).

# What is left standing after the strike, and it is what the folder rule actually rests on

**The line that distinguishes `concepts` from the other folders is the one below it**, and it is
untouched: *an `entity` is a noun with properties; a `concept` is a mechanism with consequences*.
That test never mentioned the product and never needed to.

**So the strike removes a description that had gone false, not a rule.** Nothing about which page
goes in which folder changes ([[the-folder-set-is-closed-and-tasks-is-not-in-it]]).

# Two things this does not settle

**Whether the `lessons` half of the same line goes with it.** The line is one bullet with two
clauses and the ruling names *the item*, entirely. The journal records only the `concepts` half as
leaving. **The `lessons` half is still true** — that folder is about us working on the product, and
that is exactly what its 132 pages are — so striking it would remove a description that has not
gone false. Recorded as unresolved rather than decided in either direction.

**Whether the harness-versus-product split ever gets a mechanism.** It does not follow from this,
and the deferral of 2026-08-22 is untouched.

# It is owed at the destination and is not the librarian's to write

**`job_hunt_ai_vault/CLAUDE.md` still carries the clause.** That file is what the gate reads as its
own input and is the session's to edit
([[what-the-gate-reads-as-its-own-input-is-the-sessions-to-write]]). This page is the decision it
carries out and makes no claim that the file has changed.

# The `lessons` half goes with it: the whole bullet is struck — 2026-08-23, later the same day

> **owner: Вычеркнуть полностью**

**The first of the two things this page left unsettled is answered, and the answer is the wider
one.** The bullet leaves the vault's own `CLAUDE.md` entire — both clauses, not the `concepts` half
alone.

**The session recommended keeping the `lessons` half and was overruled.** Its argument is the one
this page already states: that half had not gone false, and striking a true description is not the
same operation as striking a false one. He struck it anyway, and the ruling is his.

**It was verified first that the claim is not stranded.** `lessons` is defined independently in the
Layout table of that same file — *what we learned the hard way — failure classes, costs* — and in
`index.md`'s categories table. So what the strike removes is a duplicate definition, not the only
one ([[a-drifting-list-is-repaired-by-deleting-it-not-extending-it]]).

**Applied at the destination in the same session.** The bullet is gone from
`job_hunt_ai_vault/CLAUDE.md`; that file is what the gate reads as its own input and is the
session's to write, which is why this page said it was owed rather than doing it
([[what-the-gate-reads-as-its-own-input-is-the-sessions-to-write]]).

**The second unsettled thing is untouched.** Whether the harness-versus-product split ever gets a
mechanism does not follow from this and the deferral of 2026-08-22 still stands
([[the-harness-versus-product-split-is-recorded-and-not-acted-on]]).

# A second folder test arrived on 2026-08-30, and it is not the one left standing here — 2026-08-30

> [!NOTE] RAISED, NOT RESOLVED — the `authority:` slugs differ, so rule 3 of the gate cannot see this
> and no `CONTRADICTION` block is legal for it.

**This page says the line that survives the strike is the one below it, and names it: *an `entity` is
a noun with properties; a `concept` is a mechanism with consequences*.** That line is live in the
vault's own `CLAUDE.md` and this page calls it the thing the folder rule actually rests on.

**[[concepts-are-non-functional-requirements-and-entities-are-functional]] states a different
predicate**, ratified in the owner's words on 2026-08-30: `concepts/` are non-functional requirements
and `entities/` are functional ones.

**They are not the same test.** `session-hooks`, `docker-desktop` and `windows-console-encoding` are
nouns with properties and are functional requirements of nothing.

**Whether the new taxonomy replaces this test or stands beside it is not stated**, and the sweep of
187 `concepts/` and `entities/` pages walks by whichever answer is given. The mark stays on both
pages.

**The measurement this page rests on has moved with the corpus and is left as it stands.** It reads
*103 pages in `wiki/concepts/`, about 19 about the product*; the folder held **142** on 2026-08-30,
and a tag-based proxy that day put 126 of them outside the product. The direction of the reading is
unchanged and the number is not re-derived here.
