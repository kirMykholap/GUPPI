# The ruling, 2026-08-24

**Two pages carrying the same gauge is the same defect as two `current` pages carrying the same
`authority:`**, and it is caught by the same shape: a sweep, a sort, and a report of what repeats.

**The check itself waits.** The corpus holds almost no gauges, and a rule with no subjects is a rule
nobody can test — the vacuous pass this store keeps meeting
([[a-check-that-passed-for-the-wrong-reason-becomes-a-rule]]).

**Rejected: building it beside the decision.** A verdict written against an empty set is green on
the day it lands and proves nothing, and the way this project proves a verdict fires is by planting
an offender in the real tree
([[a-new-verdict-is-proved-in-the-real-tree-because-the-check-cannot-see-a-sandbox]]).

# What it waits on

**The marked section a gauge lives in**
([[the-measure-section-is-a-marked-region-legal-in-any-folder-and-required-nowhere]]). Until that
exists there is nowhere for a sweep to look.

# Consequence of not doing it

**None today**, and that is read off the corpus rather than assumed: it holds almost no gauges to
collide.

# Amendment, 2026-08-25 — a writer's refusal is being built, and it is not the verdict this page defers

**What is deferred here is a gate verdict over the corpus**: a sweep, a sort, and a report of what
repeats. **That is untouched.**

**What the plan of 2026-08-25 adds is different in kind** — the writer script refuses a destination it
cannot resolve as it writes, on the owner's ground that the script catches the error and the agent
reads it ([[a-gauge-is-written-by-a-script-that-runs-the-command]],
[[the-measure-writer-script-and-what-it-refuses-to-do]]). A refusal at the moment of writing is not a
sweep over what already exists, and it does not lift this deferral.

**And the destination now carries a subject as well as a page**, which is the half this check compares:
a page slug and a subject slug, because one page can legitimately carry more than one gauge
([[a-measure-line-names-its-destination-in-brackets-after-the-kind]]).

**Reported, not resolved**: whether the writer's refusal makes the swept check cheaper or redundant is
the next session's reading.
