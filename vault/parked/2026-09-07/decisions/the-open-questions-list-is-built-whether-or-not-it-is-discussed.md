# Decided 2026-08-17: building the list is not optional; having the conversation is

**Every session builds the list**: every question it opened and did not close — forks resolved
without asking, things the owner raised that were stepped past, decisions taken quietly. One line
each, each carrying a verdict.

**A session cannot judge that it has no open questions**, because not seeing them is the failure
itself. So the list is built before anyone decides whether it is worth discussing.

**The conversation is offered, not imposed.** An owner who skips it has **deferred** the questions,
and a deferral is a resolution — that is the verdict written on those lines. **Silence is not.** A
retro that ends with a line carrying no verdict has not ended.

## What it obliges

- **`Could not close` is a section of its own** in the retro form, holding the same lines again on
  their own. A missing section is caught by rule 8 of `vault-check.sh`; a missing line inside one is
  not ([[a-journal-is-judged-only-while-it-is-uncompiled]]).
- **The verdict names where the answer is written**, so an answered question leaves an artefact
  rather than a memory — the same rule the contradiction marking lives by
  ([[the-librarian-writes-unattended]]).
- It is the retro's gate rather than its payload: [[the-retro-step]],
  [[retro-interrogates-and-handoff-routes]].

## Still unbuilt on 2026-08-17, and four more questions went into a journal instead

**The document has a designed shape** — `proposals/`, `status: idea`, growing by one line each time a
question cannot be closed without the owner ([[an-idea-is-a-proposal-with-an-immature-status]]) — **and it
does not exist.** So four questions of 2026-08-17 live only in that session's journal, where nothing
carries them forward:

- whether the marker's type word is the singular or the folder name
  ([[the-marker-carries-a-type-and-governs-is-read-as-a-field]]);
- whether a **definition** rather than an imperative may render at all
  ([[an-assertion-may-render-into-claude-md-but-not-be-typed-there]]);
- which category the map's own page belongs to ([[the-map-in-claude-md-and-its-admission-test]]);
- whether `docs/` joins the governed set
  ([[docs-handoff-is-a-pointer-nothing-routes-through]]).

**Each of them is now on a proposal page**, which is the workaround, not the mechanism: a question attached
to a design is findable only by someone already reading that design
([[what-the-harness-build-waits-on]]).
