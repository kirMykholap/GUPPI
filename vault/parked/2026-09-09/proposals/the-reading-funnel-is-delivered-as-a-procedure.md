# What is built, and what is missing

**Stages one and two exist.** `bash scripts/vault-catalogue.sh` prints `authority` and `title` for
every page in one pass of frontmatter, and `job_hunt_ai_vault/authority.md` groups the slugs into
families a reader can open ([[vault-scripts]],
[[authority-becomes-the-index-and-is-required-outside-rules]]).

**No skill, agent, hook or setting names either of them.** The funnel as designed —
words → aliases → family → `title` and `authority` in one command → open at most ten → one hop along
the links — is written on [[the-folder-is-the-first-narrowing]] and is delivered to nobody as a
procedure.

**Cost of leaving it: the instrument exists and nobody is told to use it.** That is the same shape as
the mechanisms found built and wired to nothing in the same session, and it is the shape this project
already knows how to be wrong about ([[knowing-a-rule-is-not-a-mechanism]]).

# What it would take

- **A destination.** The librarian's own definition is the candidate, because the reading is done by
  the librarian in every mode and a rule copied into three skills drifts
  ([[one-librarian-behind-every-caller]],
  [[a-drifting-list-is-repaired-by-deleting-it-not-extending-it]]).
- **The form is a rule page rendering into a region**, not prose typed into the agent file, on the
  arrangement this project already uses for the admission rule
  ([[no-new-entity-where-an-existing-one-can-carry-the-claim]]).
- **The text has to keep the distinction that makes the funnel affordable**: the ten-page ceiling is
  about *opening* a page and never about searching for one. A procedure that loses that sentence
  reads as a ban on the wide sweep it is trying to require.

# What is open

**Whether it is one rule or two.** The wide sweep and the ten-page ceiling are one idea in
conversation and two imperatives on the page, and this store has ruled that a rule is one piece of
text or it is more than one rule ([[a-rule-ships-one-piece-of-text-or-it-is-more-than-one-rule]]).

**Whether `/pre-task` is a caller of it or a separate change.** The ritual's own scope is a ruling of
the same day and is not this ([[the-pre-task-enumeration-covers-every-folder-but-lessons]]).

**Nothing here is decided.** It was named as not done and put on the sprint's next list; the design
is written down because it existed only in the conversation that produced it.

# Both open questions are answered on 2026-08-22, and the delivery half is built

**The funnel is delivered as a procedure now.** It is a `wiki/rules/` page whose slice is the
librarian's own `## Start here, every time` and `## How to search`, rendered into two agent
definitions rather than typed into either
([[the-shared-reading-discipline-renders-into-every-agent-that-reads-the-vault]]).

**Answered: whether it is one rule or two. One.** The wide sweep and the ten-page ceiling ship as one
contiguous run of text into the same destinations, which is the mechanical test this store applies —
count the contiguous blocks the destination needs
([[a-rule-ships-one-piece-of-text-or-it-is-more-than-one-rule]]).

**Answered: whether `/pre-task` is a caller of it or a separate change. A second addressee.**
`governs:` names both agents inline, which is the form that landed on 2026-08-21 partly for this
([[governs-takes-a-bare-path-or-an-inline-list-and-the-block-form-is-red]],
[[the-governs-list-is-expanded-at-the-walk-and-the-address-verdict-asks-membership]]). `/pre-task` is
its own agent from the same day and is the second reader the rule was extracted for
([[the-pre-task-becomes-an-agent-and-the-ritual-is-enforced]],
[[a-pre-task-agent-and-a-post-tool-use-hook-that-writes-its-row]]).

**The section *What it would take* named a destination, a form and a sentence, and all three held.**
The destination is the librarian's own definition, plus the second agent that did not exist when this
page was written; the form is a rule page rendering into a region; and **the sentence survived
verbatim** — *the ten-page ceiling is about opening a page and never about searching for one* is
inside the slice, in the librarian's words, and it now reaches the agent that runs
`bash scripts/vault-catalogue.sh` over the whole corpus
([[the-pre-task-splits-into-a-cheap-enumeration-and-a-narrow-dispatch]], [[vault-scripts]]).

**What this page does not cover and is not owed:** the topic answer's shape stayed out of the slice on
the owner's ruling of the same day, because it is the discipline `/pre-task` must not follow. The
argument is on the rule page.

**Retirement is the owner's and is not taken here.** The delivery this page asked for is built and
the two open questions are closed, which is the condition
[[a-built-proposal-retires-once-nothing-on-it-lives-only-there]] states — but the check it also
states, that nothing on this page lives only here, is a judgement rather than a sweep, and the
regions are not marked in either agent yet.

## One claim still lives only here, and it is why this page does not retire — 2026-08-22

**`bash scripts/vault-authority.sh --near` is named by no skill and no agent as a reading step.** It
appears in the librarian's rendered admission-rule region, which is about **writing** — look a
candidate up before creating a page — and nowhere as a way to find what a question's family already
holds ([[no-new-entity-where-an-existing-one-can-carry-the-claim]], [[vault-scripts]]).

**So the funnel this page describes is delivered in its narrowing half and not in its lookup half.**
The rendered discipline carries folder, tag and full-text in that order
([[the-shared-reading-discipline-renders-into-every-agent-that-reads-the-vault]],
[[the-folder-is-the-first-narrowing]]); the register lookup, which is the step that answers *who
already owns this question*, reaches a reader only if that reader is about to write.

**That claim lives on this page alone**, which is the condition that keeps a page alive under the old
retirement test and the reason it is named here under the new one
([[a-built-proposal-stays-in-proposals-with-a-built-mark]]).
