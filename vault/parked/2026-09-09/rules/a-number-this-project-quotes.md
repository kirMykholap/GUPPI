# A number this project quotes

Where a figure came from, what its denominator is, and every way a number here has been wrong. Answers "may I write this number down".

**This rule is written into no file.** It is found by its `authority:` slug, by `.claude/hooks/serve-the-rule.ps1`, when a page carrying that slug is read. Each clause below is the claim of one decision, which keeps the reasoning and the rejected alternative it was taken against, and leaves for `archive/` when `scripts/vault-archive.sh` releases it.

# The rule text

- An unsourced number is dropped, not resolved by choosing one of the candidates ([[an-unsourced-number-is-dropped-not-chosen]])
- The criterion that every governed file carries a region is reworded to admit a file that is generated whole ([[the-criterion-on-governed-files-is-reworded-to-admit-full-generation]])
- The region-coverage figure is dated where it stands rather than patched into a new one ([[the-region-coverage-figure-is-dated-where-it-stands]])
- The region-coverage instruction carries no count, and reports the unmarked files as unchanged ([[the-region-coverage-instruction-carries-no-count-and-reports-the-unmarked-files-as-unchanged]])

# How this page was written

Drafted 2026-08-31 by `scripts/build-family-rules.py` from the family *a number this project quotes* of `authority.md`. The clause of each member is its title, because only two of the 295 prohibitions the cleanup surveyed carried a written rule text of their own.

**The slug is not the script's pick.** The script takes the `authority:` of the earliest-decided member, `unsourced-figures`, whose decision leaves for `archive/`. The slug carried instead is `coverage-denominator-source`, which [[a-denominator-is-walked-off-the-input-list]] carries and keeps — the one live `concepts/` or `entities/` page in this family, and named in the family's own definition as the denominator half of its question. The trade is stated rather than hidden: the slug is narrower than the family, and it is the only address here that a live page will answer to. `decided_by:` still names a member decision, which is what this folder requires.
