## Problem

A task that waits for a file, data or an action of the person is not shown in Plan Mode. The person learns of it only when Work Mode stops, after the thing could have been given.

## Recommend

- **What /pre-spec does with an open A line of a stop**
  - Recommended: (a) name it in the report, no block.
  - Answer: agreed, (a).
- **Which stop: tasks get an A line**
  - Recommended: (a) each stop that waits for a file, data or an action of the person.
  - Answer: agreed, (a).
- **What closes the A line**
  - Recommended: (a) the main agent closes it when it sees the thing.
  - Answer: agreed, (a).
- **Work Mode at a stop whose A line is already closed**
  - Recommended: (a) Work Mode still stops, as today.
  - Answer: agreed, (a).
- **A Case ratified in Work Mode**
  - Recommended: (b) a Case ratified in Work Mode gets one too.
  - Answer: agreed, (b).
- **The sketch Case of this session**
  - Recommended: (a) the main agent adds its A line now, by hand.
  - Answer: agreed, (a).
- **An open stop line at /carry**
  - Recommended: (a) /carry leaves a stop line out of the brief.
  - Answer: agreed, (a).
