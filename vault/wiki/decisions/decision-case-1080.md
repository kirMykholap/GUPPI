## Context

In Plan Mode of session 0947 the person proposed that in Work Mode a subagent of its own takes each ratified Case, with its whole case file as context, while the main agent stays the orchestrator. The main agent split the idea in two: the short map of the plan file, built as Case 1078, and the subagent per Case, which the person asked to discuss apart. The main agent's estimate: the main context gets lighter, the total tokens likely grow since each subagent reads the frame again, time is saved only for Cases with no shared files, and the stops of where-to-stop.md and the ticks of spec.md need a rule; to be measured before it is built. The person put it off at the close of Plan Mode.

## Problem

No Case of this session decides whether Work Mode runs each Case by a subagent of its own.

## Deferred

### [[rule-work-mode]]

Work Mode runs each ratified Case by a subagent of its own that reads its case file whole, the main agent the orchestrator, measured against the main agent running the tasks itself; put off at the close of Plan Mode of session 0947
