## Pattern

Two lessons of session 2042 share one cause: the loop after the findings of /pre-spec has no rule. After the first run the main agent sent the findings to four case-guppi agents at once and relayed each answer as it came, so rounds, Cases built again and its own question spread over four replies (lesson-prespec-findings-relayed-piecemeal-lose-the-person). The second run dispatched ask-guppi over the whole plan again for eight minutes, with no word to the person first (lesson-prespec-second-run-dispatches-ask-guppi-again).

## Proposal

A suggestion, not a decision: one rule for the loop after pre-spec findings — the Cases built again and the questions they raise shown to the person as one list of what to answer, and a second run of pre-spec that says what it checks (the whole plan or only the Cases built again) and its cost before it starts. The deferred rule-orchestration in the backlog is a possible home.
