## Pattern

Twice a Frontier line was left and fit none of the closers: in session 0014 the themes of Slice 3f that stayed on the sprint page, closed with `work` and a note; in session 1416 the failed reading of estimate-handoff-holds-each-fact-once, whose defer stands as Case 618 of the conserved Spec of 1341, refused as `defer case 618` because the check reads only the Cases of the session's own plan, then closed `work`. Each time the closer set covered only an item the session ends itself.

## Proposal

A suggestion, not a decision — a Case that names in rule-skill-hi, and in the check of guppi prespec, a closer for a Frontier item whose end stands outside the session's own plan, so the agent stops on such a line instead of picking a closer by its own judgment.
