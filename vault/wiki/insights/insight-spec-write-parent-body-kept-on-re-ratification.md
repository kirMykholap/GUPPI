## Pattern

Twice a Case ratified whole was built again after pre-spec as a parent with sub-cases and ratified again — Case 471 in session 0000 of 2026-09-28 and Case 580 in session 1441 of 2026-10-01 — and each time the plan file kept the parent's old body under its heading beside the sub-cases; the Stop checks found the pairs signed twice, and in session 1441 the Case was built again under a new id (581) that supersedes it.

## Proposal

The Spec hook of rule-spec-write could replace the whole section of a Case on its re-ratification, the parent's body included, so that only the new answer stands; the handoff of session 1441 names this as a question for the next session.
