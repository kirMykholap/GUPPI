## Trigger

after the owner's feedback on the context of a Case the agent wrote it into its local memory directory (~/.claude/projects/…/memory); the owner had it deleted

the harness offers a per-machine memory and the agent took it as the place for a working preference; GUPPI's product is the rules other developers get with the repository — a preference is a Case on a rule page or nothing, and a local memory reaches nobody else
